# Orbit releases

Download **Orbit.dmg** from the [latest release](https://github.com/hanskessler/orbit-releases/releases/latest), open it, and drag Orbit into Applications.

Orbit is a native macOS app (Apple silicon, macOS 26 or later) that finds albums in the Qobuz download store, prepares them as ALAC files, and adds reviewed albums to a Roon library. Orbit checks this page for new versions.

This repository contains release builds only.
